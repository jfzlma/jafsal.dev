# **App Name**: DataVizFolio

## Core Features:

- Profile Summary: Display a concise summary of Jafsal's experience and skills as highlighted in his resume.
- Skills Showcase: Visually represent Jafsal's skills (programming, web scraping, data engineering, etc.) using charts or graphs derived from the resume content.
- Experience Timeline: Create an interactive timeline to showcase Jafsal's professional experience, highlighting key projects and roles.
- Project Highlights: AI-powered tool that parses and categorizes projects (like the crack monitoring project) and code repositories from the resume and links to their respective URLs if provided.
- Contact Form: Allow visitors to contact Jafsal directly through the webpage.

## Style Guidelines:

- Primary color: Deep blue (#34495E), reflecting expertise and trustworthiness.
- Background color: Light gray (#F4F4F4), offering a clean and modern backdrop.
- Accent color: Teal (#008080), used sparingly for interactive elements and highlights.
- Body and headline font: 'Inter' (sans-serif) for readability and a modern feel.
- Use a clean, grid-based layout to present information in a structured and easily digestible format.
- Incorporate subtle icons to visually represent different skill sets and experiences.
- Subtle transitions and animations on scroll to enhance user engagement without being distracting.
